# 🌊 Natural Events Formula Engine

## 🛠️ Description
Computational framework for natural event formula processing.
*Note:* GitHub Actions execute in **dry-run mode only**. 

To perform live measurements:
1. Clone the repository locally on an **Ubuntu** environment.
2. Update `config/config.json` with target configuration parameters.
3. Execute `./start_measurements.sh`.
4. Review visual outputs in Firefox and complete terminal prompts.
